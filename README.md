# 嘉利采购返利管理看板

基于 **2026-10-27** 工作簿快照的自包含 HTML。保留深色、绿色强调色与全宽布局，默认显示尺寸相当于上一版的 67%，请在浏览器 100% 缩放下查看；可离线打开 `index.html`。

顶部提供 **Browser / Mobile** 显示模式切换。首次访问按屏宽选择（≤767px 为 Mobile），手动选择后在本机记住偏好。Browser 保留上述紧凑桌面布局；Mobile 使用正常缩放、触控按钮、双列指标及供应商卡片，详细字段可展开，质量/项目等明细也采用卡片。两种模式共用数据、排序、分页与导出，切换不重置负责人、周次或已打开详情。禁用本机存储时仍可正常切换。可使用 `?mode=mobile` 或 `?mode=browser` 指定首次展示；手动切换会同步该参数。

| 模块 | 功能 |
| --- | --- |
| 00 功能说明 | 四个板块的说明与跳转入口 |
| 01 整体谈判进展 | 总体/BOM/non-BOM 依次展示；金额与供应商两列，总目标、总进度共四张指标卡；BOM/non-BOM 独立分类筛选 |
| 02 负责人进展 | 保留负责人总览，第二栏显示准时完成灯号，选定个人直接查看工作清单；供应商分为已开展谈判与待开展谈判；达成率为零时弹窗不列成果供应商 |
| 03 每日/每周进度 | 下拉选择日期或周，按目标完成时间归集供应商、负责人、计划返利及占整体目标比例；待排期单列 |
| 04 供应商返利清单 | 供应商、分类、谈判策略、E–S 全字段与谈判结果；与 02/03 共用底表并互相链接 |

供应商、负责人及达成率可以点入。供应商详情包含主表 E–S 背景、谈判结果、三地质量交付与索赔明细、2027 新项目产品与原始企划量。详情可跳转负责人进展。

负责人及供应商清单以红黄绿灰色标注整行，同一灯号仍保留深浅交错底色；列标题右侧的小漏斗提供升序、降序及恢复默认顺序，已移除逐栏筛选输入。支持分页及导出整个清单。P/Q/R 空白不显示“未填”或对应标签。策略标签按降价比 <9%、份额 >60%、合作年限 >10 年生成，并可查看原值；质量标签可查看地区明细与罚款。

01 总览以两列展示金额与供应商，目标与进度上下对应。总返利目标 = 主表 F 已分配目标 + 模具汇总目标中尚未分配的部分。模具目标来自 `Non-Bom 模具618清单 1026!K37`，不写入任何一家供应商的目标。分类筛选只有完整覆盖模具目标池成员时才纳入池余额；选中部分品类时注明未拆分，不能把整池金额反复加入。

按完整精度汇总：总体 5,921.817371 万元，显示 5,922；BOM 4,720；non-BOM 1,201.817371，显示 1,202。420 万元 / 完整总目标 = 7.1%。9 家已谈供应商的实际返利 / 对应原定目标 = 420 / 1,030 = 40.8%，与整体进度分开。没有任何金额记录的范围显示“待回填”，明确的零仍是有效结果。

2026-10-28 更新：四卡布局与模具目标池已获用户确认，数据截至 2026-10-27。默认打开 01 整体谈判进展。02/03/04 沿用现有供应商目标口径。点击谈成返利金额后，Browser 弹窗占据可见窗口的大部分面积，四周各留 24px；Mobile 四周保留小边距。标题和关闭按钮固定，内容内部滚动。

## 构建与维护

编辑 `src/dashboard.template.html`、`src/dashboard.css`、`src/dashboard.js`，然后运行：

```sh
python tools/build.py
python tools/validate.py
node --check src/dashboard.js
```

`data/snapshot.json` 是规范化业务数据。`tools/import_workbook.py` 只读导入指定工作簿，保留来源行号、单位、快照日期及 SHA-256；当前源表布局和有出处的进展摘要适配 2026-10-27 版本，后续版本必须核对表头和进展文本。

```sh
python tools/import_workbook.py /path/to/source.xlsx --as-of 2026-10-27
```

原始 Excel、完整原表抽取和本机路径不得提交。无运行时外部依赖、追踪或在线回写。每次更新需核对指标、关联准确性和 1440/1920/390px 下的导航、筛选、明细、导出与字号。
