# 嘉利采购返利管理看板

**Jiali Procurement Rebate Management Dashboard**

用于采购日清日结的静态 HTML 看板：从部门目标，到负责人进度，再到周计划和供应商明细。采用深色、绿色强调色和全宽响应式布局。

## 使用方式

下载仓库后，直接用现代浏览器打开 [`index.html`](index.html)。页面自包含，不需要登录、服务器、联网或额外安装依赖。

也可在仓库根目录运行 `python -m http.server 8000`，然后访问 `http://localhost:8000`。该命令仅供本地预览。

| 视图 | 可以完成的工作 |
| --- | --- |
| 部门总览 | 查看目标分解、近期到期、成果回填和采购范围覆盖 |
| 负责人进度 | 按负责人查看目标、完成记录与本周、下周安排 |
| 行动计划 | 查看今日、本周、下周、未来七天和已过截止日任务；导出 CSV |
| 供应商明细 | 搜索、排序、分页，查看供应商详情和原始工作表定位 |

上方采购范围、负责人和周基准日筛选联动。切换周只改变计划窗口，不重建历史时点的实际状态。

## 数据版本与边界

当前版本为 **2026-10-26 离线快照**，来源文件为 `2026年10月26日-采购日清日结任务追踪.xlsx`。来源定位、内容指纹和单位保留在 `data/snapshot.json`；原始 Excel 不在本仓库内。

- BOM 清单包含 72 家供应商、6 位负责人，已分解目标 4,720 万元人民币。
- 原列标题为“5000万目标”。与明细相差 280 万元，需业务确认；94.4% 是目标分解覆盖率，不是降本达成率。
- 供应商实际完成日期与实际返利金额尚未回填。空白不解释为零成果。
- non-BOM 尚无供应商级明细，不计为零，也不纳入完整部门合计。
- “目标完成时间”不同于约谈日期。已谈数量、真实约谈计划和财务兑现需独立字段支持。

完整定义见 [指标口径](docs/METRICS.md) 和 [数据与维护说明](docs/DATA.md)。页面中的“数据与口径”也可随时查看。

## 仓库结构

```text
index.html                  可直接打开的自包含看板
src/                        HTML 模板、样式与交互逻辑
data/snapshot.json          规范化业务快照
tools/build.py              无外部依赖的 HTML 构建脚本
tools/validate.py           发布包、数据及构建一致性检查
docs/                       设计、指标、维护和发布说明
AGENTS.md                   供后续编码助手使用的项目约定
.github/workflows/check.yml 自动校验，不自动部署网站
```

## 修改与验证

需要 Python 3.10+；检查 JavaScript 语法时使用 Node.js。

```shell
python tools/build.py
python tools/validate.py
node --check src/dashboard.js
```

修改 `src/` 后重新构建 `index.html`，两者一并提交。数据更新需要核对来源、字段、单位、统计说明和数据缺口，不能只替换文件而沿用旧说明。当前未实现 Excel 自动同步、在线录入、用户认证或 caseOS 同步。

## 发布与维护

GitHub 仓库文件上传与 GitHub Pages 网站发布是两个状态。本仓库包含 Pages 所需的 `index.html` 和 `.nojekyll`，但不通过工作流自动开启网站。参见 [发布说明](docs/DEPLOYMENT.md)。

本看板包含真实业务记录，不是虚构演示数据。仓库可见性及后续数据发布范围由仓库所有者决定。未声明开源许可；如需对外授权复用，应由权利人选择许可。
