# 发布说明

## 仓库与网站

GitHub Pages 使用 main 根目录发布，index.html 为入口；.nojekyll 允许作为普通静态站点提供。推送 main 触发 Pages 更新，无需重复启用或修改可见性。

仓库工作流的数据、构建及 JavaScript 校验，与 Pages 部署分别核对。代码提交、部署成功和真实网站验证是三个不同结果，不得相互替代。

## 本次发布范围

- 保留 2026-10-28 最新主表及辅助来源，不回退本地旧快照或覆盖协作者提交。
- 发布四个业务模块及 17 个账号展示配置：14 位负责人、采购总体管理员、模具管理员、工装/设备/物流管理员。
- data/access.json 仅允许公开映射与派生哈希；本地 private/ 明文清单及交付 HTML/CSV/JSON、测试下载、日志、截图、浏览器资料均不提交。
- 公共仓库及 HTML 仍包含全量真实业务数据。前端密码仅控制正常展示，不是数据安全边界；不得宣称已私有化。
- 不上传原始工作簿、完整抽取、本机路径、GitHub 凭据或其他本机配置。

## 发布前检查

1. 以远端当前 main 为基线，记录 SHA，不用过时副本覆盖。
2. 运行构建、数据校验及 dashboard/auth JavaScript 语法检查。
3. 完成 17 账号范围验证，重点包括个人汇总下钻、本人明细、管理员边界、03 分母、筛选和导出。
4. 验证 1440/1920px 电脑和 390px 手机的弹窗、键盘关闭、局部滚动及无页面级溢出。
5. 本地完成至少 5 个会话并发、重复操作及状态切换压力测试；公共 Pages 仅有限烟雾测试。
6. 扫描发布文件确保不含任何明文密码。私密清单通过本地文件链接单独交付，不放公共网站。
7. 发布前再核对 main 未变化，非强制更新，保留共享历史；变化时先审阅并合并。

## 上线后验证

确认代码校验与 Pages 部署成功，比较线上 HTML 与本机生成版本。有限抽查登录、管理员及个人范围、四模块、弹窗及手机显示。报告实际测试规模、结果及限制；存在测试脚本不代表已经通过。

## 回滚

页面、数据和账号配置保持同版本。使用新提交回退，不改写共享历史；密码配置版本改变时要求已有会话重新登录。删除当前公开文件不能收回历史版本或已下载副本。
