# 发布说明

## 仓库与网站

将文件推送至 GitHub，只确认仓库文件已上传，不代表 GitHub Pages 已启用。仓库根目录的 `index.html` 是网站入口；`.nojekyll` 允许将其作为普通静态站点提供。

当前工作流只执行数据、构建和 JavaScript 语法检查，不修改仓库可见性，不部署网站。

现有 GitHub Pages 使用 main 分支根目录发布，推送 main 会触发网站更新；无需重复启用或修改发布设置。部署后需检查真实网站能加载、00–04 五个模块与供应商弹窗可用、分类与负责人筛选、排序和导出正常，且部署内容与本机确认版本一致，才能报告上线成功。

## 发布范围

- 页面及 JSON 中包含真实业务数据。先确认目标仓库可见性与被授权的受众。
- 公共仓库中的数据文件与页面源代码可被读取，即使未开启 Pages。
- 私有仓库不自动保证 Pages 网站私有；访问范围必须单独核实。
- 不上传原始工作簿、完整抽取、缓存、登录信息或本机配置。

## 回滚

页面和输入数据应在同一提交中保持一致。使用新提交回退业务更改，不改写共享历史。删除当前文件不等于删除历史版本中的内容，因此发布前核对数据范围。
