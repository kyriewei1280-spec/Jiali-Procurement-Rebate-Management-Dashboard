# 指标口径

所有金额以人民币万元显示，原表人民币元除以 10,000。快照日和来源版本由 `data/snapshot.json` 的 metadata 指定。

| 指标 | 计算与解释 |
| --- | --- |
| 已分解目标 | 供应商清单目标金额之和，排除总计行和 PMO 行动 |
| 目标分解覆盖率 | 清单目标 / 原列标题目标；原列标题目标仍需业务确认 |
| 本周、下周到期 | I 列目标完成日落入对应周一至周日的供应商数量及目标金额 |
| 未来七天 | 快照次日起七个自然日，不含快照当日 |
| 累计已谈、上周已谈 | 需要独立谈判记录及发生日期；当前不可计算 |
| 实际返利 | K 列非空实际金额；金额含义尚需区分谈定、签约、财务确认、到账 |
| 目标达成率 | 完整实际金额覆盖后，表内实际金额 / 同范围目标；覆盖不足时不显示完整达成率 |
| 按时完成率 | 已记录实际完成日不晚于目标日的数量 / 同时具备两日期的已完成样本数量；展示样本覆盖 |
| 已过截止日待确认 | 目标日早于快照且无有效完成记录；只表示需要核实 |
| 实际兑现 | 需独立财务确认、抵扣/到账金额、日期和凭证；不能由目标或表内返利直接代替 |
