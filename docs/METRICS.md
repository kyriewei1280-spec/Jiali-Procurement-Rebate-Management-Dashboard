金额源值为人民币元，页面总览以万元显示；索赔明细表以元显示。快照日为 2026-10-27。

| 指标 | 定义 |
| --- | --- |
| 负责返利目标 | 主表 F 列的已分配参考返利目标加总。不是采购额。未分配目标不按零处理 |
| 已记录谈成返利 | 主表 U 列已填写的有效结果之和；未来实际完成日期的记录排除 |
| 已记录目标达成率 | 同范围、有已分配目标的已记录谈成返利 / 同范围已分配返利目标；按金额加权，不平均供应商比例 |
| 负责人达成率 | 当前筛选范围内该负责人名下已记录返利 / 该负责人名下已分配返利目标 |
| 供应商达成率 | U/F；与 V 列核对。U 为空时不将 V 的公式零值当成实际零返利 |
| 供应商谈判覆盖 | 有截至快照日实际完成日期或有效结果金额的供应商数 / 清单供应商数；只表示已记录覆盖 |
| 按计划完成谈判 | T 列实际完成日期不晚于 I 列目标完成日期，限同时有两日期的已谈样本 |
| 每日/每周计划目标 | I 列目标完成时间落在指定日期/周内的供应商 F 列目标之和；不是谈判预约日期，也不是承诺返利 |
| 计划目标占整体目标 | 选中期间及筛选范围的目标 / 全表已分配返利目标；分母固定并显示，不随负责人筛选缩小 |
| 本批已记录成果 | 所选目标日期批次的供应商截至快照日已回填成果；不等于所选日期当天新增成果 |

所有源表空白金额保留为 null。已记录贡献合计为 0 仅表示当前没有金额记录，页面同时显示未回填数量。目标不完整时，达成率只覆盖已分配目标，不能声称完整部门批准目标。

## 状态

- **已达返利目标**：有记录且已谈成金额达到供应商目标。
- **已谈成部分返利**：有正金额记录且尚未达到目标。
- **已谈，结果待补/零返利**：有实际完成日但金额未填，或已明确填零。源值仍区分两者。
- **按计划待谈**：没有实际结果，目标日期未早于快照日；不证明谈判已顺利发生。
- **超期未谈（待确认）**：目标日期已过且结果未回填。缺记录不能证明未开展谈判。
- **待排期待谈**：目标日期为空且无结果。

按时与返利达标为两个维度，在负责人表及供应商明细分别显示。谈判历史以真实结果日期或记录日期排序，不生成能力评分，不补造未记录的场次。
